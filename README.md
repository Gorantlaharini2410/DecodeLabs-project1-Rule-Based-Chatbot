# DecodeLabs Project 1 – Rule-Based AI Chatbot

## Project Description

This project is a simple Rule-Based AI Chatbot developed using Python.

The chatbot uses predefined rules and responses to interact with users.

## Features

- Handles greetings such as hello, hi, and hey
- Answers basic questions
- Uses dictionary-based responses
- Uses a continuous while loop
- Handles unknown questions with a fallback response
- Supports exit commands such as bye, exit, and quit

## Technologies Used

- Python
- Dictionary
- If-Else Logic
- While Loop
- String Processing

## Example

User: hello

Bot: Hi! How can I help you?

User: what is ai

Bot: AI stands for Artificial Intelligence.

User: bye

Bot: Goodbye! Have a great day!

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run `chatbott.py`.
